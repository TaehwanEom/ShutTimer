## 3. 데이터 모델 (현재 미커밋 상태 = 최신 의도)

**Routine (변경됨):**
```typescript
type Routine = {
  id: string;
  category: string;          // FIXED_CATEGORIES 또는 custom_xxx
  steps: RoutineStep[];
  schedule?: { startTime: "HH:MM"; days: number[] };
  soundKey: string;
  active: boolean;
  endMethod: 'tap' | 'shake' | 'camera' | 'auto';
  createdAt: number;
};
```

**제거된 필드:**
- `name` — 카테고리 + 첫 step 이름으로 식별 (사용자 결정)
- `autoAdvance` (Phase 6 에서 endMethod 로 흡수)
- `dismissMethod` (Phase 6 에서 endMethod 로 흡수)

**RoutineStep (변경됨):**
```typescript
type RoutineStep = {
  id: string;
  name: string;
  durationMinutes: number;   // 분 단위 (이전: startTime/endTime "HH:MM")
  icon?: string;
};
```

**시간 흐름 모델:**
- 첫 step 시작 = `routine.schedule.startTime`
- 이후 step 시작 = 이전 step 끝난 시점 (실행 중 자동 누적, 시간 갭 무시)
- EditScreen 에선 step 표시용 시작 시각을 누적 계산만 (저장 안 함)

**기존 데이터 호환:**
- `isValidRoutine` 이 신 필드 (category, steps[].durationMinutes, endMethod) 요구
- 구 데이터 (missions, startTime/endTime, autoAdvance) 자동 탈락 → 사실상 삭제
- v1.6 미출시라 사용자 영향 0

## 4. EndMethod 4분기 흐름

| value | 흐름 |
|-------|------|
| `tap` | step 종료 → 알람 + 사운드 → 화면 탭 → dismiss → "다음 step" |
| `shake` | step 종료 → 알람 → 흔들기 2회 → dismiss → "다음 step" |
| `camera` | step 종료 → 알람 → **랜덤 MISSION_POOL emoji** + 탭 dismiss (TODO Phase 6.5: AlarmCameraMode 통합) |
| `auto` | 알람 없이 controller가 직접 `advance_auto` → RoutineRun 다음 step |

## 5. UI 구조

### RoutineEditScreen (현재 미커밋)
```
헤더: ✕ / 루틴 생성 | 루틴 편집 / 저장
━━━━━━━━━━━━━━━━━━━━━━━━━━━

[📁 카테고리 — 최상단 카드]
   아침 루틴                  >

[⏰ 시작 시간 — 둘째 카드]
   오전 7:00                 >

── 단계 ──

   오전 7:00 · 20분 >       (탭 = duration picker 다이얼)

[② 이름 입력]              ✕

반복         주중 >

(편집 모드만) [🗑 루틴 삭제]
```

### RoutineListScreen
- 카테고리별 섹션 그룹핑 (Intl.Collator 가나다/ABC)
- 진행 중 배너 (ActiveRoutine 감지, 1초 폴링, pause/resume/stop)
- 카드: 시간 + 플레이 + 토글 + step 이름 요약 + 요일
- 우→좌 스와이프 (PanResponder, 임계값 80px) → 🗑 삭제
- 섹션 [편집] → 카드 좌→우 슬라이드 + 연필 아이콘 (Animated.spring)

### RoutineRunScreen
- 헤더 = 카테고리 라벨 (FIXED_CATEGORIES + custom 캐시)
- 본문 = 현재 step.name + 카운트다운 + skip/pause/stop

### RoutineAlarmScreen
- endMethod 별 4분기 dismiss UI
- camera 모드: 랜덤 MISSION_POOL emoji 표시 + 탭 dismiss (placeholder)
- "다음 step 시작" 버튼 + 다음 step 이름/duration

### RoutineCategory / Days / Sound
- 하위 화면 3개. RoutineEdit에서 `merge:true` 패턴으로 값 반환
- 카테고리 10개 고정 (morning/evening/exercise/study/chores/**medicine(약 먹는 시간)**/work/bedtime/meal/growth)
- 커스텀 카테고리: 최대 5개, 10자, 중복 불가

## 8. iOS 64 알림 한계 (기록)

**현재 한도:** `IOS_NOTIFICATION_SAFE_CAP = 54`

**소비량 (영구 점유):**
- 1 루틴 × 매일(7요일) × 1단계 prealert = 7 슬롯
- 2단계 (30분/5분전) × 매일 = 14 슬롯/루틴 → 최대 3루틴
- 4단계 × 매일 = 28 슬롯/루틴 → 최대 1~2루틴

**임시 점유 (DATE 트리거, 발화 후 회수):**
- 단일 타이머 + reminder 3 = ~4슬롯
- 루틴 chain 알림 = ~1슬롯

**사용자분 선호:** 30분전 + 5분전 2단계
**해결 경로:** AlarmKit (iOS 26+) → 한도 사실상 무제한
