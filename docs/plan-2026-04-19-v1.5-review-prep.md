### #3 Logger __DEV__ 가드 추가

**대상:** [src/utils/logger.ts:35-44](../src/utils/logger.ts#L35-L44) `record()` 함수

**현재 문제:** Logger.info/warn/error 호출 시마다 AsyncStorage.setItem 실행. 프로덕션에서도 매 알람 사이클당 다회 호출 → 성능 경미한 영향 + 디스크 IO 무용.

**변경:**
```ts
const record = (level, tag, message) => {
  if (!__DEV__) return; // 프로덕션 가드
  // 기존 로직
};
```

**파급:**
- 프로덕션: 메모리 버퍼 + 영속 저장 비활성. Logger.getLogs는 빈 배열 반환.
- DEBUG 화면에서 로그 조회 → 빈 결과. 그러나 DEBUG 화면 자체가 __DEV__ 가드라 진입 불가, 영향 없음.
- Dev client: 변경 없음.

**검증:** dev client에서 로그 정상 기록 확인 (DEBUG → 로그 조회).

**롤백:** 가드 1줄 제거.

**우선순위:** 🟡 권장. 심사 블로커 아님. #1, #2 우선 처리 후 결정 가능.
