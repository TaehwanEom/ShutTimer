### Phase 3 — Custom Expo Module (live-activity-bridge)

**방식 결정:**
- (a) `npx create-expo-module live-activity-bridge --local` 인터랙티브
- (b) 본 창에서 `modules/alarmkit-bridge/` 패턴 그대로 직접 생성 ← **본 창 권고** (일관성)

**JS API:**
```ts
LiveActivityBridge.start({ routineId, routineName, stepName, stepEndAt, progress })
  → Promise<string>  // activityId
LiveActivityBridge.update({ activityId, stepName, stepEndAt, progress })
  → Promise<void>
LiveActivityBridge.end({ activityId, dismissalPolicy })
  → Promise<void>
LiveActivityBridge.areActivitiesEnabled()
  → Promise<boolean>
```

**Swift:**
- `Activity.request(attributes:content:)` (iOS 16.2+)
- `Activity.update(_)` / `end(_:dismissalPolicy:)`
- `ActivityAuthorizationInfo.areActivitiesEnabled`
