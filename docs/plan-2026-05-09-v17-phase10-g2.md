## 1. 작업 영역 + 사유

### 1.1 정정 대상

`AlarmKit framework 자동 LA Activity` 측 widget body 호출 ❌ → 잠금화면 LA 위젯 안 보임.

### 1.2 Root Cause

`ShutTimerAlarmMetadata` struct 측 = AlarmkitBridge Pod (= 별도 Swift module) + widget extension target (= 별도 Swift module) 측 자체 정의.
- AlarmkitBridge Pod 측 schedule = `AlarmAttributes<AlarmkitBridge.ShutTimerAlarmMetadata>`
- widget extension 측 register = `ActivityConfiguration(for: AlarmAttributes<widget.ShutTimerAlarmMetadata>.self)`
- 두 type identity 측 mismatch → ActivityKit framework 측 widget lookup ❌ → widget body 호출 ❌

### 1.3 증거

| 측정 | 결과 |
|------|------|
| 사용자분 보고 (= 시나리오 C 검증) | "앱에서 일시정지 하면 la 위젯 다 안보인다" |
| native log dump 측 `[LA-DBG-AKLA]` entry (= widget body 진입) | **0건** (= paused 30분 이상 유지에도 미발생) |
| AlarmKit observer state 추적 | ✅ (= countdown ↔ paused ↔ countdown 정상) |
| listAlarms 측 paused state | ✅ |
| widget body throttle 1초 적용 시 | 최소 1건 발생 정상 |

= AlarmKit backend state 측 정상 + widget body render 측 자체 호출 ❌. ActivityKit type identity 매칭 실패 정합.

### 1.4 Apple 공식 추천 패턴 (= 서치 결과)

> "To enable code sharing between the main app and widget extension, you create a shared framework. Both the bridge and the widget must refer to the same ActivityKit attributes type. **Any mismatch means updates won't flow.**"

ActivityKit 측 = `module-level type identity 매칭 필수` (= Codable layout만으로 ❌).

증거 URL:
- https://developer.apple.com/documentation/AlarmKit
- https://developer.apple.com/documentation/AlarmKit/scheduling-an-alarm-with-alarmkit
- https://developer.apple.com/documentation/activitykit/alertconfiguration/alertsound

**ShutTimerAlarmMetadata.swift 영역.**

```swift
// AlarmKit 자동 LA Activity 측 AlarmAttributes<ShutTimerAlarmMetadata> 단일 정의 영역.
// v1.7 hotfix #LAUnify Phase 10-G2 — 별도 SharedAlarmTypes Pod 측 단일 Swift module identity 보장.
//
// 배경 = ActivityKit framework 측 widget lookup = module-level type identity 매칭 필수.
//   직전 옵션 α (= AlarmkitBridge Pod + widget extension 측 자체 정의) 측 = 별도 module identity
//   → ActivityKit lookup ❌ → widget body 호출 ❌ → 잠금화면 LA 안 보임 root cause.
//
// 본 commit = AlarmkitBridge Pod + widget extension target 측 = 본 Pod 측 import →
//   단일 Swift module identity (= SharedAlarmTypes.ShutTimerAlarmMetadata) 보장 →
//   ActivityKit widget lookup 정합 → widget body 정상 호출.
//
// 사용 site:
//   AlarmkitBridge Pod 측 = AlarmkitBridgeModule.swift + AdvanceNextStepIntent.swift
//   widget extension target 측 = WidgetLiveActivity.swift + RoutineControlIntents.swift

import Foundation

#if canImport(AlarmKit)
import AlarmKit

@available(iOS 26.0, *)
public nonisolated struct ShutTimerAlarmMetadata: AlarmMetadata {
    public var currentStepName: String? = nil
    public var currentStepIndex: Int = 0
    public var totalSteps: Int = 1
    public var stage: String = "step"
    public var paused: Bool = false
    public var pausedAt: Double? = nil
    public var routineId: String? = nil
    public var routineName: String? = nil

    public init(
        currentStepName: String? = nil,
        currentStepIndex: Int = 0,
        totalSteps: Int = 1,
        stage: String = "step",
        paused: Bool = false,
        pausedAt: Double? = nil,
        routineId: String? = nil,
        routineName: String? = nil
    ) {
        self.currentStepName = currentStepName
        self.currentStepIndex = currentStepIndex
        self.totalSteps = totalSteps
        self.stage = stage
        self.paused = paused
        self.pausedAt = pausedAt
        self.routineId = routineId
        self.routineName = routineName
    }
}
#endif
```

**중요 측정.** struct + 모든 field + init 측 `public` 명시 (= cross-module access 위해 필수). 직전 옵션 α 측 = 동일 module 측 자체 정의 → `public` 측 불필요. 본 옵션 δ 측 = cross-module → `public` 필수.
